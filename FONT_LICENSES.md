# Font licenses

The site uses font files selected from the local `Desktop/fonts` collection.

- **Tordeo Regular** — display headings and wordmark. Personal Use Only. The supplied license notice is copied to `public/fonts/TORDEO-LICENSE.txt`.
- **Alice Regular** — reading text. SIL Open Font License 1.1. The license is copied to `public/fonts/ALICE-LICENSE.txt`.
- **Montserrat Regular / SemiBold** — navigation, labels, and interface text. SIL Open Font License 1.1. The license is copied to `public/fonts/MONTSERRAT-LICENSE.txt`.

Tordeo should be replaced or commercially licensed before any commercial deployment.
